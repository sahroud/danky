# SAHROUD FAMILY GUARD & HEALTH

برنامه اندروید برای ثبت آشکار موقعیت و مسیر، همراه با هستهٔ اولیهٔ کنترل والدین مبتنی بر رضایت.

## وضعیت فعلی اپ اندروید
- ثبت موقعیت با مجوز صریح کاربر و سرویس پس‌زمینهٔ آشکار همراه اعلان دائمی و دکمهٔ توقف.
- ثبت نقاط مسیر و محاسبه مسافت تقریبی به‌صورت محلی.
- گام‌شمار پس‌زمینه با حسگر سخت‌افزاری، اعلان دائمی و امکان توقف؛ توسعهٔ آن فعلاً متوقف شده است.
- ثبت دستی اطلاعات سلامت و آب به‌صورت محلی.
- اطلاعات GPS و سلامت در نسخه فعلی هنوز از اپ اندروید به سرور یا پنل والد ارسال/همگام‌سازی نمی‌شوند.

## بخش کنترل والدین — پیشرفت
- هستهٔ اولیهٔ API مبتنی بر Cloudflare Workers و D1 در پوشه `server/` اضافه شده است.
- طرح پایگاه داده برای خانواده‌ها، دستگاه‌های عضو، دعوت یک‌بارمصرف و آخرین موقعیت‌ها ایجاد شده است.
- کد اتصال عضو یک‌بارمصرف و ده‌دقیقه‌ای است؛ اتصال فقط با تأیید صریح رضایت روی دستگاه عضو پذیرفته می‌شود.
- API ایجاد خانواده، صدور دعوت، اتصال عضو، ارسال مختصات، دریافت آخرین موقعیت‌ها، دریافت تاریخچه محدود مسیر و لغو دسترسی را دارد.
- داشبورد والد در `dashboard/index.html` ایجاد شده است؛ ایجاد خانواده، ورود با کلید والد، صدور کد دعوت، مشاهدهٔ آخرین موقعیت، نمایش تاریخچهٔ مسیر روی نقشه و لغو دسترسی را فراهم می‌کند.

## موارد تکمیل‌نشده و مهم
- سرور هنوز در حساب Cloudflare مستقر و به دامنهٔ واقعی متصل نشده است.
- داشبورد هنوز روی دامنهٔ عمومی منتشر نشده است.
- صفحهٔ اتصال عضو با کد دعوت و تأیید صریح رضایت به اپ اندروید اضافه شده است.
- کلید دستگاه با AndroidX EncryptedSharedPreferences به‌صورت رمزگذاری‌شده در حافظهٔ خصوصی گوشی نگهداری می‌شود.
- سرویس آشکار ثبت مسیر، هنگام دریافت مختصات و در صورت وجود کلید اتصال، آن را از طریق HTTPS به API ارسال می‌کند.
- دکمهٔ توقف اشتراک‌گذاری، درخواست توقف را به سرور می‌فرستد و سپس کلید محلی را پاک می‌کند.
- ورود امن و بازیابی حساب والد، چرخش کلیدها، سیاست نگهداری/حذف داده، محدودسازی سوءاستفاده و آزمون امنیت/بار برای انتشار عمومی لازم‌اند.
- اتصال Android به API در کد پیاده‌سازی شده اما هنوز در محیط واقعی build و روی دو گوشی آزمایش نشده است.
- بنابراین این پروژه هنوز محصول کامل کنترل والدین نیست و نباید برای نظارت خانوادگی عملیاتی به آن اتکا کرد.
