# SAHROUD FAMILY GUARD & HEALTH

برنامه اندروید برای ثبت آشکار موقعیت و مسیر، همراه با هستهٔ اولیهٔ کنترل والدین مبتنی بر رضایت.

## وضعیت واقعی پروژه

### اپ اندروید
- ثبت موقعیت و مسیر با مجوز صریح، سرویس پس‌زمینهٔ آشکار، اعلان دائمی و امکان توقف.
- اتصال گوشی عضو با کد دعوت یک‌بارمصرف و تأیید رضایت صاحب همان گوشی.
- نگهداری رمزنگاری‌شدهٔ توکن دستگاه در حافظهٔ خصوصی گوشی.
- ارسال مختصات به API فقط هنگام فعال بودن سرویس ثبت مسیر و وجود اتصال معتبر.
- توقف اشتراک‌گذاری، ابتدا ثبت محلی GPS را متوقف می‌کند و سپس تلاش می‌کند دسترسی سرور را لغو کند.
- گام‌شمار پس‌زمینه و ثبت دستی وزن، قد، فشارخون، ضربان قلب و آب به‌صورت محلی؛ این داده‌ها به والد ارسال نمی‌شوند.

### پنل والد
- ایجاد خانواده و نگهداری کلید محرمانه والد.
- ساخت کد اتصال یک‌بارمصرف و ده‌دقیقه‌ای برای گوشی عضو.
- مشاهدهٔ آخرین موقعیت، زمان ثبت روی گوشی و زمان دریافت در سرور.
- دریافت تاریخچهٔ محدود نقاط مسیر و بازکردن هر نقطه روی نقشه.
- لغو دسترسی دستگاه از پنل.
- دعوت والد دوم با حساب و کلید مستقل؛ دسترسی مکانی والد دوم تا فعال‌شدن اشتراک مستقل مسدود است.

### API و پایگاه داده
- Cloudflare Worker و D1 مستقل با نام `sahroud-family-guard`.
- توکن‌های والد و دستگاه فقط به‌شکل هش SHA-256 در D1 ذخیره می‌شوند.
- کدهای دعوت ۱۶ رقم hexadecimal، یک‌بارمصرف و با اعتبار ۱۰ دقیقه هستند.
- مختصات، دقت GPS و زمان ثبت اعتبارسنجی می‌شوند؛ timestamp بسیار آینده پذیرفته نمی‌شود.
- محدودیت یک والد دوم فعال با unique index در migration شماره 0002 اعمال می‌شود.

## موارد تکمیل‌نشده و محدودیت‌های مهم
- Worker و D1 هنوز در حساب Cloudflare پیکربندی و مستقر نشده‌اند؛ مقادیر شناسهٔ D1 و origin داشبورد در `wrangler.toml` هنوز placeholder هستند.
- داشبورد روی دامنهٔ عمومی متصل به Worker نشده است.
- آزمون API خودکار با D1 شبیه‌سازی‌شده و ساخت APK در GitHub Actions انجام شده؛ آزمون واقعی دو گوشی و Cloudflare هنوز انجام نشده است.
- پنل فعلی کنترل زمان استفاده، مسدودسازی برنامه‌ها یا محدودیت سیستم‌عامل را اجرا نمی‌کند؛ محصول فعلی برای اشتراک‌گذاری شفاف موقعیت و مسیر با رضایت عضو است.
- ورود والد با کلید محرمانهٔ صادرشده انجام می‌شود؛ بازیابی امن حساب و چرخش کلید هنوز وجود ندارد.
- محدودسازی نرخ تلاش کد دعوت، سیاست نگهداری/حذف خودکار موقعیت، پایش عملیاتی، پشتیبان‌گیری و آزمون امنیت/بار برای انتشار عمومی لازم‌اند.
- اشتراک والد دوم فقط از نظر وضعیت در API مدل شده و درگاه پرداخت یا اتصال کامل به اشتراک مرکزی هنوز فعال نیست.
- داده‌های سلامت و گام‌شمار محلی‌اند و با والد یا سرور همگام‌سازی نمی‌شوند.

## راه‌اندازی زیرساخت
