# SAHROUD FAMILY GUARD

سامانه اشتراک‌گذاری شفاف موقعیت مکانی برای خانواده‌ها، مدارس و سازمان‌ها.

## معماری مصوب
- هسته مرکزی مشترک با جداسازی داده‌ها و دسترسی هر خانواده/سازمان (multi-tenant).
- ظرفیت طراحی اولیه: ۱۰۰۰ کاربر؛ توسعه‌پذیر با آزمون بار و ارتقای زیرساخت.
- طرح اقتصادی خانوادگی و طرح‌های مستقل مدارس/سازمان‌ها.
- اشتراک موقعیت فقط با اطلاع و رضایت صاحب دستگاه، همراه با امکان توقف و لغو دسترسی.

## وضعیت این پوشه
این پوشه مستقل است و به فایل‌های برنامه دوربین موجود در ریشه مخزن دست نمی‌زند.
این commit فقط زیرساخت اولیه پروژه اندروید و گردش‌کار ساخت APK را ایجاد می‌کند؛ هنوز نسخه عملیاتی چندگوشی یا سرور مرکزی آماده نیست.

## ساخت APK
پس از اجرای موفق GitHub Actions، فایل APK آزمایشی از بخش Actions > آخرین اجرای workflow > Artifacts قابل دریافت خواهد بود.

## پیش‌نیاز تکمیل نسخه چندگوشی
برای مشاهده موقعیت گوشی‌ها از راه دور باید API مرکزی، احراز هویت، پایگاه داده و سرویس بلادرنگ مستقر و پیکربندی شوند. تا قبل از آن، هیچ موقعیتی به سرور ارسال نمی‌شود.
