## قابلیت‌هایی که هنوز فعال نشده‌اند

API فعلی عمداً فقط‌خواندنی است. موارد زیر هنوز پیاده‌سازی و در محیط واقعی فعال نشده‌اند:

- ورود و احراز هویت کاربر
- ساخت حساب و اتصال هویت خارجی
- ثبت و مدیریت دستگاه‌ها
- نشست و خروج امن
- نقش‌ها و کنترل دسترسی چندحسابی در API
- صدور، اعتبارسنجی و ابطال مجوز نرم‌افزار
- طرح‌ها، اشتراک‌ها و پرداخت
- پنل مدیریت مرکزی

تا زمان انتخاب و پیکربندی ارائه‌دهنده هویت، نباید endpoint نوشتن یا ورود با کلید ثابت، رمز ذخیره‌شده در D1، یا Secret داخل APK/JavaScript فعال شود. CORS احراز هویت نیست.
